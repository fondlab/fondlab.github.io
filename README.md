# fondlab.github.io
Personal developer site for Fondlab

The site is served by GitHub Pages. Edit `index.html` and `zh/index.html` together for bilingual content. The language picker remembers the user's preference in browser storage.

When an independent app is ready to share, add it under `apps/<app-name>/` and link to it from the homepages. Use that same directory for its privacy policy and support page. Add terms or an account deletion page when the app calls for them. Add a public developer contact address once one is designated for the site.
